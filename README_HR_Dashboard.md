# 📊 HR Analytics Dashboard

A Power BI dashboard project focused on analyzing employee data and
presenting key HR insights through interactive visualizations.

## 🎯 Project Objective

The objective of this project is to analyze employee information and
create an interactive dashboard that helps understand:

-   Employee distribution across departments
-   Employee attrition
-   Attrition by job role
-   Attrition across different age groups
-   Overtime and attrition patterns
-   Average monthly income by department
-   Overall workforce trends

## 🛠️ Tools Used

-   **Power BI**
-   **DAX**
-   **CSV Dataset**

## 📊 Dashboard KPIs

The dashboard includes the following key performance indicators:

-   **Total Employees**
-   **Attrition Rate**
-   **Average Monthly Income**
-   **Average Performance Rating**
-   **Average Years at Company**

## 📈 Dashboard Visualizations

The dashboard contains:

-   Employees by Department
-   Attrition by Department
-   Attrition by Job Role
-   Attrition by Age Group
-   Overtime vs Attrition
-   Average Salary by Department

## 🎛️ Interactive Analysis

The dashboard can be explored using HR-related filters such as:

-   Department
-   Job Role
-   Gender
-   Age Group
-   Business Travel
-   Overtime
-   Marital Status
-   Salary Slab

## 💡 Key Insights

The dashboard helps identify:

-   Departments with higher employee attrition
-   Job roles with higher employee turnover
-   Age groups with higher attrition
-   Differences in average income across departments
-   Overtime-related attrition patterns
-   Overall employee workforce distribution
